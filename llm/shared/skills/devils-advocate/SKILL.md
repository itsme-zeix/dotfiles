# Devil's Advocate

Use the proposal or focus supplied with the invocation, or infer it from the current discussion. Do not modify files or implement anything.

State the proposal and objective. If either is genuinely unclear, ask one focused question. Present the strongest evidence-based case for the proposal, including the constraints that make it attractive.

Identify load-bearing assumptions and verify them against available sources or repository evidence where practical. Label uncertainty. Stress-test the proposal through plausible failure scenarios, inversion, Socratic questions, and likely blind spots. Present at most three material objections, each with the strongest rebuttal and a proportionate mitigation.

Conclude with one verdict: ship it, ship with changes, or rethink this. State what evidence would most likely change the verdict. Do not manufacture objections to fill the format.
